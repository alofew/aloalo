# ALOALO 쇼핑몰 (학습용)
순수 HTML/CSS/JS로 만드는 쇼핑몰. 이후 React로 이전 예정.

## 실행
`python3 -m http.server 8000` 후 http://localhost:8000 접속

## 로드맵
- [x] 1단계: 메인 / 상품 목록(필터·정렬) / 상세 / 장바구니(localStorage)
- [ ] 2단계: 디자인 다듬기, 검색, 주문 페이지
- [ ] 3단계: React(Vite)로 이전

## 면접 문제은행
`interview/` — 생기부 기반 면접 예상 질문 연습 페이지 (타이머·핵심 포인트·꼬리질문)
